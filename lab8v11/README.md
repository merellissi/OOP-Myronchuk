# lab8v11

**Студент:** Мирончук
**Варіант:** 11

Реалізовано метод `CollectionHelper<T>.Count(IEnumerable<T> collection, Predicate<T> predicate)`,
який повертає кількість елементів, що задовольняють умову. Логіка написана власним кодом
(цикл `foreach` і лічильник), без використання LINQ.

## Демонстрація
Метод продемонстровано для `List<int>`, `List<string>` та `List<Product>`
з використанням лямбда-виразів.
